# 固定 LGB 预测：最低持有期与换仓数量的含费对照

已完成预先声明的五组、三个期间，共15条完整账本。**8条有效，7条因信达证券换股终值证据不足而无效；暂不训练20日模型，也不切换模拟盘。**

有效的2025年结果表明，降低换手值得继续研究：原基线净亏6.88%，四组限制均转正，净收益为3.21%—6.93%。但四条跨年连续候选都未通过期末估值核验，不能把账面正收益当作已验证盈利，更不能据此声称达到年化20%。

## 固定条件与核验

本轮没有训练模型、生成新预测或改动特征、训练样本、费用、滑点、交易规则、历史成分和估值要求。使用原有两折LGB及563,489条预测，10万元初始资金，目标20只，保留排名前40，仍每5个实际交易日检查调仓。信号和下单数量依据上一实际交易日的预测与价格。

五组是原基线，以及最低持有10／20个交易日与每次最多尝试换出2／5只的四种组合。换出上限计不同证券的计划退出尝试，不保证实际成交。初始建仓和已有空位不占换出额度；锁仓及超过换出上限的持仓保留原股数。拒单后继续沿用原执行器，可能临时超过目标20只，已另行记录，没有临盘换标的或事后补选。

持有年龄按“计划执行日的实际交易日序号−本次持仓实际首次买入日序号”计算，买入日为0。部分卖出、追加买入不重置现有证券持仓起点；已核实送转与换股继承来源起点。正数待配送转权益仍保留原起点，结算后的零碎权益本身不延长已清仓的持仓周期；清仓后重新买入重新计龄。

在任何候选运行前，先精确复现2025、2026和跨年连续三个原LGB基线：摘要所有字段、最终状态、10类原始记录，CSV逐字节、JSON逐值比较均一致。所有新路径完成后再次核对原模型、预测、源数据与实现SHA。独立复核全部237个结果文件，以及15条曲线、成交费用、换手和最低佣金占比，均与报告吻合。

## 2025年独立账户：五条均有效

以下顺序均为“扣费净收益／最大回撤／累计单边换手”。换手按实际买卖成交额之和÷2÷期间平均净资产计算，不能把累计倍数写成年换手。

- 原基线：-6.88%／9.38%／20.61倍。
- 持有至少10日／最多换出2只：+6.93%／5.75%／4.52倍。
- 持有至少10日／最多换出5只：+3.21%／5.95%／10.92倍。
- 持有至少20日／最多换出2只：+3.68%／5.70%／4.43倍。
- 持有至少20日／最多换出5只：+4.13%／7.49%／9.00倍。

“10日／2只”成交206笔，交易费加滑点2,449.06元；基线930笔、10,951.91元，成本下降77.64%。平均资金投入比例88.66%，接近基线88.51%，改善并非主要来自少持仓或大幅空仓。所有组的成交都触发最低5元佣金，因此主要降低的是付费次数及交易金额，没有降低假设费率。

不能把成本差直接加回原净值作因果分解：限制换仓同时改变持仓、现金与后续整手数量。20日／2只成本更低，但收益低于10日／2只；20日／5只又优于10日／5只，不能推导出“持有越久越好”。模型排序信息与实际持有路径之间仍有差距。

稳定性方面，10日／2只在2025年有7／12个月盈利，基线为6／12；118个126交易日滚动窗口中，前者全部为正，最差+2.12%、中位+10.51%，基线分别为−3.76%、+3.81%。这些窗口大量重叠，且出自已观察年份，不能视为118次独立的未来验证。

独立年度账户各从10万元开始，连续账户保留跨年资金、持仓和调仓节奏，不能把两年度收益相乘冒充连续结果。固定预测的全池排序质量完全相同；交易限制没有提高模型预测本身的准确率。

交易约束本身已核实：所有候选卖出年龄都能从实际持仓及公司行为起点重建，未知起点和低于最低持有期的卖出均为0。连续账户四组的实际卖出持有期中位数依次为30、15、30、20个交易日；这项成交审计成立，但不能解除末日估值造成的绩效无效状态。

## 无效原因与下一步决策

7条无效路径均仅在2026年10月19日触发相同问题：仍持有信达证券SH601059。四条连续路径各300股；三个无效的2026年独立账户分别为300、200、300股。9月14日最后旧标价15.56元对应账面4,668元或3,112元。9月15日至10月16日的18个停牌交易日有原始状态证据，按声明口径保留旧价；10月19日摘牌后，旧价格不再提供合格终值。

现有已核实原公告能确认停牌、摘牌和0.5210换股比例，但不足以确认截至声明终点的实际新增中金股份登记、分配、交付及上市可交易日期，也没有可靠终值。公告还涉及全体股东尾数排序与随机分配，300×0.5210=156.3不能直接当成已收到156股或157股。这里的结论是**当前保存证据不足**，不是断言现实中该日一定没有完成相关手续。

因此没有把信达旧股伪装成可卖资产，也没有按中金现价虚造新增股份、现金兑付或零损失退出。完整区间、原参数和无效路径全部保留；没有删股、截短期间或另加参数以获得好看的结果。分析另列仅末日将相关旧标价全部扣零的敏感性，属于终值风险诊断，不是新的回测，不计算对应回撤、年化或滚动收益，也不使原路径变有效。

仅作这一末日扣零敏感性时，四条连续账户相对初始资金的变化依次为+11.71%、−3.89%、+7.45%、−1.08%。这些数字不是合格回测收益，不能据此选优；它们说明未知权益的处理足以使部分组合的正负号改变。

运行前已规定：同一候选的三条路径都有效，且连续收益提高、回撤不恶化、换手下降，才算执行改进；还须2025、部分2026和连续账户都净盈利，才支持保留现有5日信号继续未来验证。本轮四组均未满足“三条有效”，合格候选为空，程序输出 `resolve_invalid_paths`，没有切换策略。

**当前暂缓20日模型训练。** 优先补齐并实现信达换中金的待换股权益、实际分配及可交易时钟核算；保留本次原始产物，另封新的执行核算版本，继续逐笔复现基线与全部四组后再判断。若以后完整有效的低换手比较仍不能稳定盈利，再把20交易日标签作为独立的新训练实验，重新划分训练、验证和未见测试区间；不会在这些已经看过的窗口继续搜索到盈利为止。

这次是已观察历史区间的研究对照，不是新的未来样本外证据。账面净值不代表真实券商可成交清算价值；分红税继续使用保守最高预留，原有11项税务来源分类未解决事项仍单独披露，没有利用持有期变化假设税费返还。
