# 历史数据与样本外研究工作流

本轮补齐可审计的历史数据输入、股票池约束和固定规则样本外研究入口。数据校验不通过就停止，不用未复权价格代替复权价格，也不以工作日猜测交易所开市。研究结果与个人账户账本独立。

## 安装与运行

建议使用 Python 3.12。这个研究入口只需要轻量依赖，不要求先安装 Qlib、训练模型或连接券商。

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-research.txt
python main.py research --help
```

### 在网页操作

构建前端后，当前 `.venv` 环境直接运行：

```bash
.venv/bin/python main.py serve --host 127.0.0.1 --port 8000
```

浏览器打开 <http://127.0.0.1:8000>。数据库无用户时，可在本机同源首次设置页面自行创建管理员；系统安全生成固定登录签名并持久保存到被 Git 忽略的 `config.local.yaml`，已有签名不覆盖。已有账户继续使用原密码。远程初始化等场景可使用 `.venv/bin/python main.py user create-admin` 交互回退；网页首设不对远程或代理访问开放。

1. 进入「系统设置 → 历史研究数据」，核对东方财富价格、BaoStock 日历、固定资产池及锁定区间，主动提交下载。页面打开本身不开始采集。网页初始偏好为串行间隔 3 秒、4 次有限尝试、15 秒单次超时，可在配置中心保存后续默认值；需要新采集批次时明确选择重新采集。
2. 下载结束后检查快照的来源、覆盖与缺口。缓存复用保留原采集时间，完成状态本身不能代替查看数据覆盖。没有匹配当前协议的完整快照时，回测按钮保持不可用。
3. 在「回测验证 → 样本外研究」选择协议和匹配快照，提交后台研究任务。锁定的参数在网页只读；不同成本协议各自产生结果，不能在看到最终收益后覆盖原协议。
4. 从研究结果列表打开净值与回撤、三个时间分段的指标、连续观察块和分页成交/持仓/信号明细。默认目录中的 CLI 研究结果也会自动发现。页面读取结果前核对文件校验和，损坏结果显示校验失败。

下载与回测共用单研究任务互斥。任务状态和失败信息保存在本地，刷新页面可继续查看；服务中断后保留「已中断」，不自动重发联网请求。损坏任务保留原文件并单独标记「记录损坏」，不当作已完成或失败业绩，也不阻塞其他正常记录。价格响应缓存的同日续传与跨日刷新规则仍按下文执行。

「系统设置」还包含配置中心、模型维护和账号安全。配置中心只保存当前真实使用的白名单字段：研究下载偏好、AI 参数与凭据、传统回测/信号默认值和模拟引擎风险比例。配置采用 revision 并发检查、文件锁、0600 原子本地写入与变更审计，保留其他本地项；公共 `config.yaml` 不被网页覆盖。环境变量控制的字段只读，密钥只显示是否配置，空输入保留、显式清除才删除。密钥和服务地址提示重启；普通参数供新实例或后续任务使用。修改这些默认值不会修改已锁研究协议。模型维护的 Qlib 数据更新与双价格研究快照独立。

「持仓与账本」中的账户 NAV 是带报价时间与缺价提示的观察估值，不是官方收盘净值或剔除资金流影响的 TWR。券商 CSV 用于只读核对，不会导入、覆盖或自动修正账本。配置中的模拟风险比例也不是手工成交录入的拦截规则。

「运行与备份」提供本地运行检查和管理员 SQLite 一致性全库备份。备份包含用户密码哈希、账户、分析和聊天等数据库内容，不读取或打包 `config.local.yaml`、行情、模型和研究产物；网页没有恢复或覆盖入口。需要迁移这些文件时，应另行妥善保存，不能把数据库备份当作整个项目备份。

### 先锁规则与数据声明

[当前默认的东方财富实验说明](research/m2_etf_eastmoney_spec.json)明确：固定池 SH510300、SH510500、SZ159915；2014—2018 开发段、2019—2020 验证段、2021—2025 最终历史样本外段。60 个交易日动量、每 20 个交易日调仓、选 1 只；动量非正时持有现金；买卖每边各 5bp（3bp 费用加 2bp 滑点）。没有网格寻优或模型拟合。价格来自东方财富，交易日历来自 BaoStock。

```bash
python main.py research lock
python main.py research prepare
```

`lock` 和 `prepare` 默认使用东方财富声明及其独立协议。`lock` 不读取行情。协议绑定参数、资产池、真实选池日期、数据源、区间与复权方式；重复执行同一声明不会改变锁定时间。修改声明需要另命名协议，不能覆盖原实验。2026 年锁定规则并回看 2021—2025 年，不等同于在 2021 年已预注册的前瞻验证。

原 [BaoStock 实验说明](research/m2_etf_spec.json)与协议保留作历史记录。初始请求在下载阶段发现 ETF 复权标识混杂，已拒绝生成可用于回测的完整快照。异常记录见 [数据质量事件](research/data_quality_incidents.json)。不降低该项校验来凑出结果。

也可明确指定默认的 [东方财富数据声明](research/m2_etf_eastmoney_spec.json)与协议；它保留相同资产池、日期和策略参数：

```bash
python main.py research prepare \
  --spec docs/research/m2_etf_eastmoney_spec.json \
  --protocol docs/research/m2_etf_eastmoney_protocol.json
```

两个协议对应不同实验；不会自动切源或混接不同来源的 raw/adjusted OHLC。已有数据用 `--refresh` 重新下载时，旧快照仍保留。CLI 下载失败写入 `output/research/data/failures/`，网页任务失败保存在 `output/research/jobs/`，均不会登记为成功快照。网页只执行三个东方财富主/成本敏感性协议，原 BaoStock 协议及其已有 CLI 结果保留只读。

### 限流、冷却与恢复

东方财富下载串行执行，相邻请求默认至少间隔 2 秒；每个证券分别请求完整区间的 raw 与 adjusted 数据。同一持久缓存目录使用操作系统非阻塞锁，另一个 `prepare` 进程会立即报告忙碌；异常退出会释放锁。请求时间也保存在该缓存中，重启后仍遵守间隔。不同缓存目录的进程不共享锁，不应并行请求。可主动放慢速度并缩短重试次数：

```bash
python main.py research prepare \
  --min-interval 5 --max-attempts 3 --request-timeout 20
```

参数范围为 `--min-interval 2..60` 秒、`--max-attempts 1..6` 次、`--request-timeout 1..60` 秒。默认重试上限 4 次，单次超时 20 秒。连接故障、408、429 和 5xx 采用有限退避及少量随机等待；服务端给出 `Retry-After` 时按它等待。单次等待超过 60 秒时，保存 `blocked_until` 并结束，稍后再运行原命令。冷却状态跨进程重启保留，`--refresh` 也不能绕过。

403 表示请求被拒绝，立即停止；200 响应中的 HTML、错误 JSON、错误证券、残缺字段、无效日期、非有限价格或量额单位异常也停止，不自动重试。不会轮换主机、IP、代理或数据源来绕过限制。出现 403 后应等服务恢复再手动尝试，持续失败就保留失败记录，不能据此宣称数据已更新。

命令行将可恢复响应保存在 `output/research/data/download-cache/`。每次下载有独立 generation；只有通过单响应校验的数据才原子写入缓存，并绑定完整请求参数、generation 和 payload SHA-256。恢复时重新核对这些身份、校验和与数据结构，成功快照还要通过 raw/adjusted 日期配对、因子、交易日历及覆盖检查。响应缓存与可回测快照是两个阶段，缓存里有文件不代表已有完整研究数据。

同一上海自然日内，失败后再次执行原命令可复用该 generation 已验证的响应，只请求缺失部分；存在未完成下载时不会默默返回更早的成功快照。跨上海日期的未完成下载必须显式 `--refresh` 开新 generation，raw 和 adjusted 都重新请求。旧 generation、旧快照继续保留，不混入新批次。缺少某日 bar 本身不能证明接口分页或截断，也不能补造价格或用工作日日历填齐。

已有完整快照且没有未完成批次时，原命令会复用经过校验的旧快照，不发送价格更新请求；下载日期和覆盖截止日仍以原 manifest 为准。只有显式 `--refresh` 才发起新采集，刷新失败不会把旧数据改标成最新数据。

快照的 `download_provenance` 记录 generation、上海日期、每个响应原始 `fetched_at`、请求与 payload 校验和，以及 `first_response_at/last_response_at`。恢复使用的响应保留原下载时间，不改成恢复时刻。这个时间窗口表示采集范围；本地 generation 和同日约束都不能证明供应商多次请求间从未修订复权数据，因此 `atomic_supplier_vintage_verified=false`。它也不代表历史当时可知的复权版本或最新行情。明确刷新时全部重新下载，不能把不同 generation 的前复权/后复权片段拼成新历史。

### 核对数据后再运行

`prepare` 成功会打印 `Snapshot:` 路径。以下命令中的路径应替换为这次实际输出，不是随意选择一个旧目录。

```bash
python main.py research inspect --snapshot <Snapshot路径>
python main.py research run \
  --snapshot <Snapshot路径> \
  --protocol docs/research/m2_etf_eastmoney_protocol.json
python main.py research plot \
  --run-dir <Run路径> \
  --output output/research/oos-curve.png
```

运行目录每次独立，保存 `manifest.json`、`report.json`、协议副本及 `returns/folds/positions/trades/signals.csv`。再次运行同一数据、规则、代码和依赖环境，应得到相同的结果与 CSV 校验和；目录名和实际生成时间可以不同。

## 价格和交易日历的口径

- 同一数据源分别下载未复权 OHLC 和后复权研究 OHLC，逐证券、逐日期配对；保留观察复权因子、来源、版本与下载时间。数据集明确 `execution_ready=false`。
- 原始成交量统一为股/基金份额，成交额为人民币。东方财富原始手数按公开接口的单位转换，保存来源说明，并用成交额/成交量与价格区间交叉检查；不使用复权成交量来限制真实股数。
- `calendar.csv` 保存完整自然日的开市/休市标记，缺日期、重复日期或范围外记录均拒绝。单只证券停牌不被当作交易所休市。
- 未上市、停牌与缺价保持各自的缺口。必要持仓估值或选中标的的执行价格缺失时，回测停止，不前向填充或把该日收益设为 0。
- ETF 复权价格出现超过 40% 的日内、隔夜或相邻收盘跳变时阻止保存，要求核验动作或来源。这个筛查不能证明每次分红与公司行为都已完整处理。
- 日级日历可用于完整历史研究。日内会话规则仅覆盖模块明确支持的现代现金股票范围，不把当前竞价制度倒套所有历史年份或所有基金品种。

研究按连续复权价格计算分数敞口收益，不把复权价格用于整数股撮合。分红、送转、合股、配股的实际现金与证券变化尚不能通过价格比值完整重建；真实账户回测仍需要单独的公司行为账本。

## 历史成分的导入与阻断

`HistoricalUniverse` 区分三种输入：

- `fixed`：明确声明的固定研究池。选池日期是实际日期；今天选择 ETF 再回看历史，仍存在回看选池限制。
- `snapshot`：当前或指定查询日的供应商快照。周度 `updateDate` 不等于指数调样生效日，禁止向前/向后扩展为整个历史成员。
- `index_pit`：带完整历史基线与调样来源的有效区间。需要按当时可知信息、成员数量及覆盖范围审计。

历史区间输入包含 `instrument`、`effective_from`、exclusive 的 `effective_to`、`known_at`、`source`、`source_url`；有限退出还需要 `exit_known_at` 和 `exit_source_url`。公告日期与生效日期是两项事实。日期未注明公告时刻时，保守按当日结束后可知，不能假定早于 15:00 信号。

`index_pit` 还需 `expected_size` 和完整的 `coverage_evidence`（历史基线/官方调样日志或已验证逐日成员）。信号时点还不知道未来执行日的退出时，明确拒绝，不能偷看未来退出并返回 N−1 只成员。

```bash
python main.py research universe-import \
  --input <有来源的成员区间JSON> --output <新的版本化股票池JSON>
python main.py research universe-audit \
  --universe <股票池JSON> --start 2021-01-01 --end 2025-12-31 --require-pit
```

这些审计核对输入的结构、覆盖与可知性，不能代替核实人工提供的来源材料。当前尚未取得完整、精确生效的沪深300历史基线与调样日志，因此本次固定 ETF 研究不能称为“已消除指数成分幸存者偏差”。

旧版 Qlib 全量/增量下载现在只把当前指数成分写入 `*.current_snapshot.json`，不再生成覆盖整个历史的 `csi300.txt/csi500.txt`。已有历史文件保留并标记尚未审计。只有通过 PIT 审计的数据才能通过 `HistoricalUniverse.write_qlib()` 导出历史成员区间。

## 样本外结果如何解读

信号只使用前一交易日及更早的收盘；旧仓位承担隔夜收益，下一交易日开盘调仓后承担日内收益。费用、滑点与首日入场成本都进入净值；最终样本外每 126 个交易日划一个观察块，跨块不重置持仓或重复收取初始入场费。

训练段与验证段是固定规则诊断，不是机器学习拟合。最终段比较动量、同成本等权再平衡、同成本 SH510300 买入持有，以及 SH000300 价格指数。价格指数不含分红且不扣交易成本，不能把所有差异都解释成策略能力。

每边 10bp、20bp 的成本敏感性协议也已在看最终收益前分别锁定，只用于检查稳健性，不用于挑选并替换主结果。20% 年化和 15% 最大回撤是研究筛选目标，不是已经取得的结果。

完整历史成分、逐项公司行为、券商级成交、最低佣金、成交量冲击、涨跌停排队、完整 T+1 与真正未来模拟盘仍需进一步验证。
