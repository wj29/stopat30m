# 是否调整模型：固定预测期限诊断与待换股权益核查

**当前保留原LGB，不直接调参或重训。20日标签有研究依据，列为下一次独立对照候选；尚无证据表明重训20日模型会提高扣费收益。** 本轮完成了真实冻结预测的5／10／20日诊断，以及信达证券待换股权益的来源核验和独立参考估值。没有训练、生成新预测、修改原账本、切换模拟盘或下单。

此前[低换手实验](A6_LGB_TURNOVER_RESULTS_20261020.md)已经显示，同一模型减少换仓后，10日／2只组合在有效的2025和部分2026独立账户净收益分别为+6.93%、+1.84%。实际卖出持有期中位数却达到15—30个交易日，原模型目标只有5个交易日，值得检查目标与持仓周期的匹配；这并不等于现有模型已经失效。

## 同日期、同股票的预测期限诊断

使用原563,489条固定预测，没有重算分数。先逐项精确复现三个期间的原5日质量诊断，再计算全部9组原生期限结果和9组配对结果。运行前封存5／10／20三个期限、原模型、预测、源数据、设计及实现SHA，没有按结果追加期限或挑样本。

配对结果要求三个期限使用相同的信号日期与股票交集，都有完整的t+21成熟未来窗口。股票只需在信号日属于当时沪深300／中证1000，不要求未来继续留在指数；缺失或非正端点明确剔除并记数，不填成零收益。这仍是依赖未来端点可观测性的标签诊断，可能有标签可得性偏差，不能代替真实交易验证。

以下按5日／10日／20日顺序，列平均每日横截面Rank IC与正Rank IC日期占比：

- 2025年，223个共同信号日、288,665个股票日期对：**0.0770／0.0783／0.0801**；正相关日期占比64.57%／61.43%／56.95%。
- 2026年截至10月19日，169个共同信号日、219,006个股票日期对：**0.0653／0.0808／0.1345**；正相关日期占比60.95%／62.72%／68.64%。
- 连续期间，412个共同信号日、533,494个股票日期对：**0.0652／0.0691／0.0885**；正相关日期占比61.17%／60.19%／58.98%。

20日平均排序相关较强，但改善主要出现在2026年，2025年提升很小，连续期间的正相关日期占比反而下降。Rank IC是预测分数与未来收益的横截面秩相关，不是收益率、交易胜率或净利润；均值为正也不意味着每天稳定。

连续配对期间包含2025年12月3日至12月30日额外20个跨年信号，独立年度诊断因期末成熟限制不包含这些日期。作为事后覆盖核查，这20天的平均Rank IC按5／10／20日分别约为−0.0677／−0.1308／−0.2079，进一步说明不能只合并好看的年度摘要，也不能宣称20日在各时期都更稳。原数据与这些日期全部保留，没有调整样本或参数。

多日标签彼此重叠，不把412天当作独立检验。配对缺失端点股票日期对分别为837、488、1,447；所有覆盖、共同证券名单、原生及配对日结果均已保存。5日原生连续Rank IC仍为0.07020957，与配对的0.06517863样本不同，不能混写。部分2026年不是全年结果。

## 标签与训练隔离的正确时序

当前标签为 `Ref($open,-6)/Ref($open,-1)-1`：信号t收盘后，t+1开盘进入、t+6开盘结束，实际持有5个交易日，需要6个未来交易日的完整依赖。

10日标签应为 `Ref($open,-11)/Ref($open,-1)-1`，20日应为 `Ref($open,-21)/Ref($open,-1)-1`。20日需要21个未来交易日隔离，不能把原式的6直接改为20。当前冻结实现有多处6日成熟、资格及协议校验，未来需要独立期限版本，旧模型与原实验保持不变。

若进行下一次训练，先只比较H5控制组与H20实验组，固定特征、参数、数据来源和同一执行规则，不同时叠加新的成本阈值、择时或大范围调参。若要识别标签本身的作用，两组都用共同t+21成熟样本、相同训练期处理器与相同交易规则；年度训练截点为2024／2025年末时，最后共同成熟信号分别为2024-12-02／2025-12-02。原5日模型分别训练到12月23日，直接复用它作H20对照还会混入训练尾段和处理器变化，只能称业务对照。

现有CSRankNorm目标下的LGB分数也不是已校准预期收益，不能直接拿分数与佣金bp比较。成本准入若另做，应使用训练期内部、按时间隔离的折外校准，并作为独立实验；减去每日共同指数收益也不会自动实现行业、市值或beta中性。

本轮没有启动上述训练。所有这些已看过的2025—2026区间都属于回顾研究，真正推广仍需冻结模型之后的新未来记录。

## 待换股权益：已确认什么，仍缺什么

新补齐并视觉核验了中金10月16日正式实施公告、10月17日提示，以及信达10月16日实施提示，共13页。可以确认：10月16日收市登记在册的信达A股股东，享有每股换取0.5210股中金A股的比例权益；整数尾差按余数排序及同尾随机分配处理。[中金正式实施公告](https://static.cninfo.com.cn/finalpage/2026-10-16/1225606336.PDF)

已保存的官方目录查询截至10月20日，尚未找到对应的实际新增股份登记完成、具体账户整数分配及上市确认。这个结论限于本次官方目录与已核原件，不声称现实中绝对未完成。公告明确，登记日、登记完成及新增上市是不同事实；账户暂不显示市值也不代表经济权利为零。

依据每条原账本10月16日实际收市快照，7条受影响路径中6条各300旧股，对应条件数量156—157股；1条200旧股对应104—105股。不能伪造实际交付数量，也没有向实体持仓添加中金股份或增加可用现金。

独立核算层统一使用已核实10月19日中金原价收盘32.10元作为**条件经济暴露参考标价**：300旧股的区间参考值为5,007.60—5,039.70元，200旧股为3,338.40—3,370.50元。计算只从原净值扣除已经包含的信达旧标价一次，再加这一参考值，保留原现金、既有中金实股及信达现金红利。

它不是待换股权本身的可成交报价、无条件公允价值界或保证回收额。实际登记与流动性仍未知，不能据此把原7条无效回测改成有效。全部原始标记保持**8有效、7无效**，没有按新的参考收益选策略。原来的零回收敏感性也只是风险情景，并非公告证明权益为零。

核对全部15条路径：8条未受影响曲线逐字段不变；7条只改终点的独立参考估值，原先所有日期、现金、成交与实体持仓均未修改。区间回撤以当日下界除以历史上界峰值重新计算；没有套用旧回撤或使用中间值。参考估值与数量、旧标价扣除均已独立重算核销。
