# H5 与 H20：共同训练样本的真实模型对照

**完成4次真实拟合、6条含费账本，不支持切换为20日模型。** 2025至2026-10-19的两个连续账户均有效：新H5扣费累计收益**+11.42%**、最大回撤**17.01%**；H20为**+4.76%**、**21.43%**。H20换手更高，未通过事先冻结的收益、回撤、换手联合门槛。

另有一条H5独立2026账户因信达证券待换股权益未定价而无效，全部保留，没有用于模型选择。当前不推广H20，不追加参数搜索或重训来追逐已看过的历史结果。

## 六条结果：年度账户与连续账户分别看

收益均为扣除实际模拟费用后的累计收益，回撤使用净值下界相对历史上界峰值计算；换手为买卖总实际金额除以2及日均净值，不作年化。2026仅截至10月19日。

- **2025独立账户，243个交易日，均有效：**H5收益+3.61%、回撤8.71%、换手8.24倍；H20收益+5.88%、回撤7.67%、换手8.81倍。
- **2026独立账户，189个交易日：**H20有效，收益+11.63%、回撤24.68%、换手7.68倍。H5无效，保留的账面诊断为−0.53%、18.38%、7.03倍，**这些H5数值不是通过验证的业绩**。
- **连续账户，432个交易日，均有效：**H5收益+11.42%、回撤17.01%、换手15.03倍；H20收益+4.76%、回撤21.43%、换手15.81倍。H20净收益低6.66个百分点、回撤大4.42个百分点；这不是年收益11.42%／4.76%。

联合门槛五项中仅“H20三个账户均为正收益”通过；六路径全部有效、连续收益更高、回撤不差、换手不高四项均失败。即使待换股核算最终修复，当前连续收益／回撤／换手结果仍不支持推广H20。

## 问题不只是佣金，跨年执行路径也很重要

连续H5实际685笔成交，H20为712笔；全部触发最低5元佣金。H5佣金3,425.00元、过户费31.33元、印花税759.93元、滑点4,006.58元，费用加滑点合计8,222.84元；H20对应3,560.00／33.08／806.64／4,449.06元，合计8,848.78元。两组还分别保守预留红利税1,068.71／1,311.31元，现金分配取整准备均为0。

H20多记录的费用加滑点625.94元、税准备242.60元，共868.54元；终值却少6,655.01元。观测差额表明，不能简单把H20落后归咎于佣金，预测排序与持仓路径也需要负责。费用会影响后续可买数量和分红资格，这**不是独立无费重跑或精确因果分解**，不能把费用加回净值当作真实毛收益。

连续账户的126交易日重叠窗口共307个：H5正收益占比74.59%、中位收益2.97%、最差−12.07%；H20为53.75%、0.48%、−16.15%。两组正收益月份占比都为50%。这些重叠窗口不是独立试验，不能当作未来获利概率。

H20独立2026账户为+11.63%，连续账户的2026年内分段却为−1.05%；H5连续账户2026年内分段为+7.54%。独立账户1月5日以现金重新建仓，连续账户承接上一年持仓，固定20交易日相位的当年首次调仓在1月28日。两者本金、持仓及调仓相位不同，不能拼接年度账户收益代替连续账户，也不据这次结果搜索更好看的起始日。

H20连续平均持仓市值占比89.66%，H5为88.00%；更高敞口没有带来更高净收益。尚未增加同风险、行业／市值匹配的全收益基准，绝对盈利也不等于已证明超额收益。

## 一条无效路径的具体原因

H5独立2026账户于8月4日买入后，末日仍持有信达证券`SH601059`共200股；9月30日曾尝试退出，但被停牌／未知交易状态门禁拒绝，最后可用旧股原价为9月14日15.56元。10月19日账本明确记录`unknown_price_instruments`及`unpriced_delisted_claims`，全路径1个会计无效日，未提前停止或删除终日。

[A7公告核查](A7_MODEL_HORIZON_AND_EXCHANGE_20261020.md)确认了换股比例权益，但未确认本账户实际交付、整数分配和可交易日期。本轮没有把条件参考估值导入现金或正式收益。其余5条路径保持有效，不把这条失败隐去，也不把H5连续账户的有效性误写成H5所有账户均有效。

## 本次只检验预测目标

[A7 固定预测诊断](A7_MODEL_HORIZON_AND_EXCHANGE_20261020.md)给出了研究20日目标的理由，但没有证明重训会提高利润。这次实际训练两组独立 LightGBM：H5 预测下一开盘至第6个未来交易日开盘，H20 预测下一开盘至第21个未来交易日开盘。

- 2025账户使用2020—2024训练数据；2026账户使用2021—2025。两组都清除21个未来交易日，最后共同训练信号分别为2024-12-02、2025-12-02，标签最晚成熟于各自上年末。
- 同年度两组共用相同的股票日期行、158项官方 Alpha158 特征及仅拟合一次的特征处理器。实际进入原生训练器的特征、标签及样本索引分别计算SHA；两个标签独立做横截面秩归一化，不能把同一个标签训练两次。
- 股票只需在信号日属于当时沪深300／中证1000，不要求未来继续留在指数。共同训练样本要求t+1、t+6、t+21合法且有可观测端点；推理不按未来标签筛选。
- 固定100轮、学习率0.03、31叶、深度6、叶节点最少100行、L2为1、随机种子20261019；不调参、不早停。总预算4次拟合、6条新含费账本。
- 两组都每20个实际交易日调仓，目标20只、保留排名前40；连续账户跨年不重置调仓相位。没有叠加A6的最低持有期或单次卖出数量限制。

**新H5是重新拟合的配对控制组。** 它与旧A5的训练尾段、处理器及执行频率不同，也与A6的持有期／换仓数量限制不同；不能把新结果相对旧结果的全部差异归因于20日标签。

实际完成4次原生拟合，每个模型100棵树、158项特征。2025每组1,543,595条训练样本，2026每组1,543,991条；同年度两组训练索引、处理器和实际消费的特征哈希相同，标签及模型文件哈希不同。预测分别为每组316,743／246,746条，双组共1,126,978条。训练于2026-10-20 09:54:47 UTC完成，09:55:10 UTC再封存执行声明，随后才启动新账本。

## 账本与事先冻结的门槛

初始资金10万元，原始价格、整手、T+1、涨跌停／停牌限制、最低5元佣金、万三佣金、过户费、当时印花税、每边2bp不利滑点及价格最小单位取整共同执行。现金分红、送转、已确认换股及保守红利税准备沿用原核算。源数据、历史成分、原生模型、预测和执行代码在新收益计算前分别封存。

先逐字段精确复现旧模型2025、2026、连续三个完整基线，全部通过后才计算新模型收益。H5／H20各运行2025、2026截至10月19日、连续2025至2026-10-19三个账户，保留全部交易、拒单、现金、权益和估值记录。

H20同时满足以下条件才取得本轮历史研究候选资格：六条账本全部有效；连续扣费收益高于H5；连续最大回撤和换手不差于H5；H20三个账户全部正收益。无效路径保留诊断数值，不通过删股票、提前截断、换股参考标价或假设现金回收改变有效性。

## 解释边界

2025—2026区间此前已经查看，这次是冻结设计后的回顾对照，不能称新的未来样本外证据。两个年度训练窗重叠，不能当成四次独立统计验证；共同未来端点筛选也仍有标签可得性偏差。

每组自有标签的Rank IC使用不同成熟尾段，不能据此直接宣称H20相对H5的排序能力提高；主对照是相同日期和执行规则下的实际含费账本。CSRankNorm分数不是校准后的预期收益，不能直接与费用bp比较。

早期训练行情仍包含保存的社区Qlib基座，没有独立重采每条旧历史，也不等于保存了当时可获得的全部行情修订／复权版本；真实日线不证明可获得开盘队列优先权或真实券商成交。11项分红税分类未完全确定，继续保守预留，不冒充全部税务事实已核清。原A7待换股参考权益没有进入本轮正式收益。

本轮不修改活动模拟盘或券商账户。年化20%仍是研究目标。

新H5也只是本轮配对控制产物，没有自动替换旧模型。优先补齐待换股权益的正式登记／交付／可交易时钟，随后以冻结策略的新未来记录验证低换手执行；本轮不根据已看过的2025—2026收益继续扩大参数网格、变换起始日或挑选年度。
