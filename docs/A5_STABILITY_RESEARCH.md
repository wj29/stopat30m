# 历史成分验证：2025—2026年独立扩展

目标是检验沪深300、中证1000历史成员中的个股信号，能否在个人账户规模、实际交易约束及成本后持续取得收益。2023—2024年已有的[验证结果](A5_UNION_RESULTS_20261020.md)保持原样；新期间单独声明、单独训练、单独开账，不能把两段账户拼成一条2023—2026年连续净值。

## 数据通过后才训练

新验证的执行年份固定为2025、2026，结束日在运行前明确声明为2026年10月19日。按信号日的官方历史成分选股，不能用今天的1300只成员回填过去，也不能要求训练样本在未来仍留在指数中。2026年的结果覆盖年内已发生区间，不能直接称为全年收益。

市场审计有13项检查，涵盖原价、复权时序、实际交易日、停牌、历史ST、上市及代码有效期、公司行为、退市/并购身份、原始响应来源和完整税款预留。来源预检即使没有剩余问题，也不等于正式授权：训练入口明确要求新期间的正式审计、全部检查通过、`source_preflight_only=false`，以及匹配的行情快照、历史成分和股票身份SHA。

原始供应商响应始终保留。发行人证据仅形成另有出处的消费视图：参考价注释不能改变实际收到的现金或股份；补入供应商漏记事件、纠正实际分派总额必须使用独立操作。每条公告绑定原PDF、日期、相关页的视觉核验及原始响应，不用价格反推分红后冒充公告事实。

回购股份不参与分红时，个人股东实际收到的每股金额可能高于交易所计算除权价所用的折算金额。两个量分别保存、分别使用。同日两个财务期间的分红只有在发行人明确合并实施，并且精确原始行和公告总额吻合时，才能形成合并事件；不会通用地按股票、日期求和。

历史更名也不能直接回填：例如300114与302132有明确代码生效边界。当前代码的供应商回溯别名数据，不能据此当成该代码在生效前真实交易的价格；原始响应保留，但合法日期消费视图和模型缺失检查单独处理。

## 税款和现金必须对得上

普通现金分红沿用固定20%个人税款预留，属于保守研究假设。送红股与资本公积转增分别核实实际比例、每股面值和资本来源；不能因供应商字段为空就默认免税，也不能把完整税率剪到100%便称已缴足。

对于现金分红覆盖不了的额外税额，按登记日实际持仓，在除权日下单前从已有现金作完整预留。分类仍未决的资本来源明确保留未决标签并按最高口径预留，不能伪称已经证明应税或免税。不按持股期退回税款，预留时间也不冒称券商真实扣税时间。

若现有现金不足，停止并标记该路径无效，报告只保留诊断，不能用截断的净值表示完整期间表现。税款预留与新增的发行人分钱舍尾预留先在候选账本计算，全部成功才提交，避免后一步失败却留下前一步扣款。

对于已经取得原公告明确证据的分钱舍尾，另记独立现金费用，抵消旧账本四舍五入可能多计的一分钱，保留原税款而不减税。例如301308在2026年6月2日每股实际现金为0.9907442元，200股实际毛额按公告舍尾为198.14元。这个规则只适用于已绑定证据的事件，其余现金事件仍使用原声明的分钱规则。不能把它描述成完整复刻券商分红、税款与中登尾数分配。

## 固定模型和含费对照

每个执行年使用前五个日历年的训练数据，并按六个实际交易日隔离未来标签。2025年训练窗口为2020—2024年，2026年为2021—2025年；处理器只在对应训练窗口拟合。比较原固定MOM60与Alpha158 LightGBM，不依据已观察的验证收益搜索参数或提前停止。

执行假设保持为初始10万元、目标20只、保留排名40、每五个交易日调仓；万三佣金、每笔每方向最低5元，另计过户费、当期印花税和不利滑点。滑点向不利方向按一分钱档位取整，实际成本可能超过名义2bp。使用原价、T+1、板块数量规则、每日ST与停牌状态及涨跌停限制；涨跌停报价不代表排队能够成交。

每年单独开账与跨年保留资金、持仓的连续账户都要运行。主要看有效账本的扣费收益、最大回撤、月度及滚动区间分布，并同时解释成交次数、最低佣金占比、滑点、换手和信号排序质量。价格指数只作市场环境参照；没有股息再投资与投资成本的指数差额，不能直接称为alpha。

这属于事后重建的历史检验。更早训练基座没有逐日全部独立重采，供应商历史是当前获取的版本，逐日状态也不等于已经取得公告时点的数据快照；因此不包装成全新的未来样本外。科创板等交易权限另有假设，日线数据无法证明现实队列、深度和冲击成本。

## 可复用入口

使用项目根目录的`.venv/bin/python main.py research`，新增三个独立命令：

- `ashare-stability-freeze`：声明固定年份、结束日、模型、费用、有效性规则及源文件校验值，可通过`--rule-original-evidence`绑定补充交易规则原件。
- `ashare-stability-train`：检查正式13项门禁后训练年度模型，保存处理器、标签成熟度和源文件清单。
- `ashare-stability-validate`：运行含费账本；任一路径无效则保留诊断报告并以非零状态退出，避免自动化把无效结果当成功。

三个命令均可加`--help`查看参数。原数据、旧声明与已有实验目录不能覆盖；新一轮必须使用新输出路径。模型预测、源输入及执行代码在运行前后重新核验。新研究不会自动切换每日模拟账户、启动任务或连接真实券商订单。
