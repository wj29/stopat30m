# 历史成分联合验证：2025—2026年扩展结果

已完成中证1000及沪深300历史成员数据补齐、正式来源核验、年度重训和六条含费回测。**当前两种固定策略均没有稳定盈利证据，也未达到年化20%的目标。** LightGBM具有正向排序信息，但在10万元、20个目标持仓、五交易日调仓的实际约束和费用后仍然亏损；固定MOM60的信号和回撤更差。本轮不切换每日模拟账户。

## 收益、回撤与跨年差异

各自从10万元开始的独立年度账户：

- 2025年：MOM60净收益−12.97%，最大回撤32.04%；LightGBM净收益−6.88%，最大回撤9.38%。
- 2026年截至10月19日：MOM60净收益−42.92%，最大回撤52.56%；LightGBM净收益+0.22%，最大回撤19.23%。这是189个实际交易日的年内结果，不是全年收益。

从2025年开始，跨年保留资金、持仓和调仓节奏的连续账户：

- MOM60：累计净收益−47.98%，期末52,024.53元，最大回撤52.63%。
- LightGBM：累计净收益−13.14%，期末86,861.58元，最大回撤25.80%。

2026年LightGBM独立年度账户小幅盈利，但连续账户同年仍亏损6.72%。年度重置会改变初始持仓、资金、整手数量和调仓起点，不能把独立年度收益相乘，冒充跨年实测路径；这种差异也说明结果对账户状态敏感。

六条路径均覆盖完整声明期间，账务无效日为零，期末价格均新鲜，没有未定价退市资产。连续两策略各有1日已证停牌旧价估值，属于声明的账面净值口径，不能称为现实当日可成交的清算价值。

## 稳定性与成本诊断

连续账户共22个月，其中2026年10月为部分月份。LightGBM仅10个月盈利，MOM60仅8个月盈利。181个252交易日滚动窗口中，LightGBM盈利窗口占11.60%，中位收益−5.51%、最差−23.34%；MOM60分别为13.26%、−15.96%、−43.64%。这些窗口大量重叠，不能视为181次独立检验。

LightGBM在2025、2026年的日均Rank IC分别为0.0688、0.0771，连续成熟标签427日均为0.0702，正向日期占61.36%；MOM60连续均值为−0.0427。排序相关性支持继续研究LGB信号，但不能证明前20名组合、可负担股票筛选及持仓缓冲后的扣费收益。

连续LightGBM成交1,770笔，全部触发最低5元佣金：佣金8,850元，实际约为成交额12.18bp，高于名义万三。过户费73元、印花税1,796.71元，交易费合计10,719.71元；不利滑点9,720.66元，交易费加滑点合计20,440.37元，另有分派税款预留1,015.53元。432个实际交易日的单边换手累计38.64倍，不能写成年换手。

连续MOM60成交1,280笔，最低佣金触发率同样为100%，交易费加滑点10,409.63元，另有税款预留259.44元，单边换手累计25.11倍。它的成本较低但损失更大，且Rank IC为负，问题不能仅归因于费用。

对MOM60在2026年7月的大幅亏损另做来源归因复核：独立年度账户当月损失53,586.69元，连续账户损失33,505.03元，逐持仓价格损益与账户变化精确闭合。核查13只主要贡献股票的原始响应SHA、报价、量额、除权参考价及公司行为，未发现未记权益或估值矛盾；最大单股分别只贡献月损失的8.64%、14.13%，所有7月持仓均使用当日原价收盘标记。独立核对的中证1000价格指数同期也下跌19.69%。这项复核证明绑定数据与账本一致，不冒称另一供应商已逐条验证全部股票报价。

六条实际路径均未持有需要额外税款预留的五项事件，额外税与分钱舍尾费用实测为零；相关完整预留规则及来源核验仍然执行，不能把未触发说成已实际支付。模型包、账本费用、公司行为流水与统计已逐项核销。

费用会改变后续现金、数量和持仓，不能将20,440.37元直接加回净值来宣称“无费盈利”。本期间尚未重跑新的成本反事实情景，旧时期的情景结果也不能直接外推。下一步应把预期信号收益与最低佣金、滑点和换仓成本放在同一准入条件中，先检验较少换仓是否改善净收益；现有收益不足以支持更换运行中的模拟策略。

沪深300、中证1000价格指数同期累计分别为+6.09%、+12.43%，只作市场环境参照，未含股息再投资和投资成本，不将差额称为严格alpha。

## 验证范围与固定口径

执行期间为2025年1月2日至2026年10月19日，按信号日的沪深300、中证1000历史成分选股。期间历史成员实际并集为1,645只。官方成分重建覆盖2018年至2026年10月19日，每个实际交易日均保持300+1000只且两池不重合。

2025年使用2020—2024年数据训练，2026年使用2021—2025年数据训练，均保留六个实际交易日的标签隔离。比较原固定MOM60与Alpha158 LightGBM，固定100轮、31叶、深度6、学习率0.03，不使用验证收益搜索参数或提前停止。

两折分别保留1,564,694、1,564,964条训练样本，最后信号日分别为2024年12月23日、2025年12月23日，标签执行端点均不晚于对应12月31日。共保存563,489条固定预测，2025年316,743条、2026年246,746条，训练时未要求样本未来继续留在指数中。

每条独立年度账户从10万元开始；另有从2025年开始、跨年保留资金和持仓的连续账户。2026年仅覆盖截至10月19日的已发生区间，不能写成全年收益。此前2023—2024年[结果](A5_UNION_RESULTS_20261020.md)及原始产物保持原样，不能把两段独立账户拼成2023—2026年连续净值。

目标持仓20只，排名保留范围40，每五个实际交易日调仓。按万三佣金、每笔每方向最低5元、过户费、当期印花税及2bp不利滑点执行；滑点还须向不利方向取一分钱价格档位。使用原价、T+1、板块数量规则、每日ST、停牌、涨跌停及历史交易规则，日线涨跌停报价不能证明排队可成交。

## 执行修复与模型字节复用

首次含费执行在2025年8月29日停止，未生成正式收益报告。独立复现发现，旧排名适配器虽然计算了开盘预算缩减后的股数，生成权重却仍使用原计划的缩减前股数；失败日回退后的权重仍合计105.0396%。这不是浮点精度容差问题，不能通过放宽100%权重限制解决。

新期间单独使用修正适配器，权重分子改为实际缩减后的股数，保留原选股排名、冻结计划、已持有股份、交易费用及原账本。测试验证可用现金不足的场景、实际成交不超过缩减后股数，以及未缩减场景的成交、费用和期末状态与旧实现完全一致。旧适配器、失败运行及原协议保留，旧2024年独立MOM60结果的两天适用性问题亦已在[原报告](A5_UNION_RESULTS_20261020.md)标明。

修正后新建执行声明v2，严格核对新旧协议只有声明时间和执行实现校验值不同，训练参数、数据、历史成员、费用和交易规则全部相同。复用接口逐文件检查原模型、处理器、原生内嵌声明、历史成分证明和全部预测，仅重新绑定顶层执行声明；两年度原生模型、全部CSV、过滤结果及原训练时间逐字节保留，不冒称再次重训，也不根据初步收益调整模型。运行前后继续追溯原模型包、两版协议和来源SHA。

## 数据补齐与异常处置

正式市场检查13项全部通过，包含707,376行原价和状态记录、3,509项公司行为；未解释的除权参考价、复权时序断点及待处理来源问题均为零。每日交易状态和历史ST来自原始逐日记录，不把缺失报价推断为停牌，也不把缺失交易日变成假日。

1,198只证券的最新增量中，1,130只通过原严格衔接，68只未通过并完成整段重建。其后全窗口检查发现的109只模型缺失或复权断点证券，又依据完整失败清单补取原价和复权历史。超时、失败响应及停止记录保留；42只剩余证券按事先声明的三个日期区间采集，再以原请求、逐行位置、获取时间及SHA组合，不伪装成供应商的一次整段查询。

异常处置没有放宽原价格、因子、成交均价或float32精度门槛：

- 302132按官方2025年2月17日代码生效边界消费，之前的供应商别名回溯数据保留但不作为合法价格。另因首合法日后复权基准错误，以独立官方前复权因子生成整个合法区间的一致派生基准；406行合法日线重新生成全部七个模型字段，生效前仍为缺失，不借用300114行情。首日以后的前后复权比值须满足同一个六位因子舍入区间，全部原后复权OHLC也与独立元数据逐项核对。
- 三只IPO证券的首日或前两日模式标注异常，通过独立上市身份、实际交易日及官方因子核实后形成明确派生视图，原标注保留。
- 301238在2022年7月20日的原成交额导致成交均价低于日最低价。独立新浪原件的全部OHLC、成交股数与原记录一致，仅成交额不同；只在派生视图使用698,092,445元这一整数精度成交额，原供应商记录未改。整段1,051个交易日的OHLC与成交股数亦独立匹配。

112项除权参考价问题均以独立原公告关闭：94项只注释参考参数，17项补入漏记现金事件，1项纠正已记录的分派总额。实际每股现金、送股、转增与交易所计算参考价所用折算参数分开保存。同日多项分红只有发行人明确合并实施并绑定精确原记录时才合并，不按日期通用求和。

199项非现金分配事件完成消费及完整税款覆盖核对；仍有11项资本来源的税务分类未完全定性，保留未决标签并按完整最高口径预留，不能称为已经证明全部免税或应税。现金分红预留之外，另有五项额外税额合同，按登记日实际持仓在除权日下单前从已有现金完整预留。现金不足必须停止并标记路径无效，不借款、不剪裁税额、不删除持仓。

对于301308已由原公告明确的分钱舍尾，另记独立现金费用，抵消旧账本可能多计的一分钱，原保守税款不减少；不把这条特定规则推广为所有现金分红规则。税款与分钱舍尾预留先在候选账本计算，两项都成功才提交。

## 结论的适用边界

这仍是当前供应商历史版本及有效成分事后重建的历史稳定性检验。更早训练基座未逐日全部独立重采，历史成员也不等于完整公告时点快照；不能包装成全新的未来样本外。302132的修正使用同一供应商的独立因子查询及官方方法，不能称为另一供应商确认的后复权价格。

价格指数只作行情背景，未包含现金分红再投资与投资成本，策略和它们的差额不是严格alpha。日线回测也不证明真实订单深度、冲击或队列成交，研究假设已具备涉及板块的交易权限。

本轮不会自动切换已有每日模拟账户，不连接真实券商订单。
