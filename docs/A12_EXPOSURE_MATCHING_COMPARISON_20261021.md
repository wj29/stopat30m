# A12：原策略与7.5%方案的相近资金投入含费对照

资金投入匹配通过了两个独立年度的事前门槛。相近证券资金占比下，7.5%方案的扣费收益、回撤和成本均优于“原策略加每日现金调节”；因此，没有证据把此前的改善只归于多留现金。但新增调节自身增加了最低佣金，不能把全部收益差额称为少换仓的纯因果贡献，也不能据此认定模型更有效。

9条完整账本已完成，7条有效；原策略和匹配组的连续账户均保留信达权益估值缺口，无效且不参与归因。2025年7.5%方案仍不及原策略净收益，联合结论为`INCONCLUSIVE_INVALID_ORIGINAL_REFERENCE`。当前20只模拟盘继续原配置，不推广7.5%或每日现金调节，不重训。

## 事前冻结的方法

- 仅三组：原hold10_cap2、原7.5%双边金额限制、原策略加独立现金调节；各自运行2025、2026截至10月19日和跨年连续账户，共9条账本。六条旧对照的摘要、最终状态及全部原始账本精确复现后，才计算三个新增账户。
- 三组均使用同一原A5年度H5预测、历史沪深300＋中证1000成员和原价／交易状态／公司行为，每账户10万元。原核心仍为目标20只、保留前40、至少持有10个实际交易日、每5日检查、最多2只退出意图。没有重训或重算预测。
- 新增账户在原核心交易之后，每个实际交易日最多执行一次现金调节。目标只取已封存7.5%参考账户的前一个实际收盘证券风险价值上界／净值下界；不读当天或未来目标，不使用全期平均数。第一个计划建仓批次不调节，连续账户跨年不重置。目标未知或不合法就跳过并留证，不外推、不裁剪。
- 当前资金占比与目标相差不超过1个百分点时不交易；超出时只按现有证券价值同比例调整，再作合法整手及固定余量分配，不新增选股。不以拒单余额再分配、不作第二批补单。原核心与现金调节分开执行并标记，不能合并相反订单来规避最低佣金。
- 现金调节明确是新增政策，可以突破核心策略的最短持有期和退出数量限制；实际成交仍遵守原T+1、整手、涨跌停、停牌及资金限制。所有实际成交更新持仓起点；部分卖出保留原起点。其佣金、税费与滑点真实入账，计入最终净收益，不作线性缩放或无费收益加回。
- 匹配检验预定为：双方账本有效、同实际收盘证券风险敞口已知覆盖至少99%、平均有符号偏差绝对值不超过1个百分点、平均绝对偏差不超过2个百分点、95分位绝对偏差不超过5个百分点。阈值使用序列化数值的Decimal和线性95分位，包含边界。另报最大偏差、超过5个百分点的天数／连续长度、未知日期及会计口径`1−现金/净值`，后者不替代证券风险敞口。
- 原交易规则、最低5元／万三佣金、过户费、历史印花税、每边2bp与最小0.01元不利价格单位保持不变。滑点已在成交价中，图表和净值不重复扣；红利税与现金舍入准备另列且已计入净值。
- 匹配不通过即保留失败，不按结果修改规则。即使通过，也只说明证券资金占比接近，不说明行业、beta、波动或持仓路径相同；三方收益桥只能作描述性净收益比较，不能宣称纯现金或纯换仓的因果贡献。回撤按各自净值曲线核算，不能相加分解。
