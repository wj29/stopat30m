# A13：降低现金调节频率与最低调节金额的含费验证

四组固定规则都降低了每日现金调节的实际成本，但没有一组同时通过两个独立年度的资金匹配门槛；不能宣布找到相近投入下更好的替代策略。500元两组在2025年通过匹配，并改善每日调节组的净收益、回撤、成本和笔数；2026平均证券资金占比却高出参考组1.073／1.122个百分点，超出事前1个百分点上限。1000元两组两期均不匹配。

21条完整账本全部完成，15条财务有效；除7.5%参考组外，其余六条连续账户均保留信达未标价权益，无效且不作推广依据。正式结论`INCONCLUSIVE_INVALID_REFERENCE`，四候选跨两个独立年度的预定改善诊断均失败。保持当前20只模拟盘、原模型及定时任务不变，不放宽门槛、不追加参数、不自动切换。

## 计算前冻结的规则

- 四组候选固定为每3个实际交易日／每笔至少500元、每3日／1000元、每5日／500元、每5日／1000元。规则于2026-10-21 17:03北京时间、任何新增历史候选收益计算前封存；不根据结果追加组合或修改门槛。
- 原策略、原7.5%方案及A12每日现金调节共三组旧对照，各运行2025、2026截至10月19日及跨年连续账户；九条摘要、最终状态与全部13／14类原始账本精确复现后，才计算四组候选的12条新账本，共21条。
- 模型、历史沪深300＋中证1000成员、原价行情、交易状态及公司行为均沿用封存原件；使用原A5年度H5预测，每账户独立10万元。原核心仍为目标20只、保留前40、至少持有10个实际交易日、每5日检查、最多2只退出意图。没有新训练、预测或下载。
- 现金调节周期从账户第一个实际交易日索引0锚定：索引0只作原建仓、不调节；3日组首次在索引3，5日组在索引5，此后取对应整倍数。跨年不重置，不按上次成功成交顺延；非计划日不读参考目标、不调用现金调节执行器、不补做历史成交。
- 计划日只取封存7.5%同期间账户前一个实际收盘已知的证券风险价值上界／净值下界。固定1个百分点不交易区间，不读当天或未来目标，不使用全期平均值，不结转过期目标。
- 保留A12现有证券价值同比例分配、合法整手向下取整、按股数余量及代码作一次额外合法整手调整。完成这一步后才筛最低金额，不把小单凑成大单、不向其他证券转移被筛掉的金额、不累积虚拟额度。
- 最低金额为每个拟议订单按原引擎不利成交价格计算的成交本金，包含每边2bp、最小0.01元不利价格单位及合法限价裁剪，达到门槛即可。无法证明合法成交价的订单作明确的事前跳过，不伪造实际拒单或成交。
- 买单先服从原ST日买入上限及整手规则，再按原成交缺口金额从大到小／代码顺序，预留完整拟议本金及舍入后的佣金、过户费等；不能完整支付就整单跳过，不缩成小单。实际拒单不释放预留给后续名字；不重新分配、补单或合并相反订单。每笔实际调节成交必须达到冻结门槛，否则明确报错。
- T+1、停牌、涨跌停、整手、佣金万三且最低5元、过户费、历史印花税和原公司行为核算保留。原核心和现金调节分开支付真实费用，滑点已在成交价格中，不重复扣除或加回毛收益；所有实际成交更新持仓计时，部分卖出保留原起点。
- 现金调节是显式新增政策，最短持有期和退出数量限制只约束原选股核心，不能声称全部调节也遵守原hold10_cap2。参考目标或当前风险未知就跳过留证；无法建立合规开盘净值时只按原特定异常停止新路径，保留实际已发生成交和最后真实收盘，不填假净值。

## 事前比较门槛

沿用A12证券资金占比匹配标准：双方账本有效、同实际收盘风险已知覆盖至少99%、平均有符号偏差绝对值不超过1个百分点、平均绝对偏差不超过2个百分点、线性95分位绝对偏差不超过5个百分点。阈值使用Decimal并包含边界；不删未知日期后改写收益，不以`1−现金/净值`填补未知证券风险。

逐期描述性比较还要求原策略、7.5%、A12每日组、该候选四条路径均有效，候选和每日组的资金匹配都通过。跨两个独立年度的改善诊断要求候选均做到：净收益不低于每日组、保守回撤不恶化、实际费用加滑点严格降低、现金调节成交笔数严格减少。失败或无效时保留收益账本，但不给合格排名或自动切换建议。

回撤从初始10万元和历史净值上界峰值计算；换手为实际买卖金额÷2÷日均净值，均不年化。即使通过匹配，也只证明证券资金占比接近，不说明beta、行业、波动或持仓路径相同。三方收益桥只作已扣费的会计恒等式，不能计算纯现金与纯换仓的因果贡献。

当前20只前瞻模拟盘、原模型、资金、账本和原生定时任务保持原样。不自动推广、重训、改时钟或接入实盘券商；信达旧换股核算继续暂缓。过去已经查看的历史窗口属于回顾性研究，不是新未来样本外或稳定20%年化的证据。
