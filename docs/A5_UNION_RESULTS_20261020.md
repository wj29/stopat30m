# 历史成分联合回测：2026年10月20日验证结果

本轮已完成2023—2024年沪深300、中证1000历史成分的来源核验、年度重训和含费回测。**当前两种固定策略均不足以投入持续模拟盘替换，更没有达到年化20%的证据。** LightGBM有正向排序信息，但10万元、20个目标持仓、每五个交易日调仓的组合，在成本与回撤上仍然不合格。

## 实测收益与回撤

两个年度单独从10万元开始的结果：

- 2023年：MOM60净收益−19.80%，最大回撤38.15%；LightGBM净收益−15.94%，最大回撤20.46%。
- 2024年：MOM60净收益−23.39%，最大回撤34.73%；LightGBM净收益+12.59%，最大回撤23.35%。

跨年保持同一账户、不重置资金和持仓的结果：

- MOM60：2023—2024累计−32.60%，期末67,404.23元，最大回撤55.21%，按252交易日约定年化−18.57%。
- LightGBM：累计−9.03%，期末90,969.68元，最大回撤33.82%，同口径年化−4.81%。其连续账户2024年收益为+8.22%。

独立年度实验会重置资金、持仓和调仓起点，因此不能将两个独立年度收益相乘，冒充连续账户结果。六条路径的账务有效性检查均通过，没有未定价退市持仓，没有期末陈旧价格。期间已证停牌仍存在旧价账面估值：连续MOM60共10日、LGB共3日，不能把这些估值称为当日可成交清算价格。

## 稳定性还不够

连续账户两种策略都只有10/24个月盈利。LightGBM的252交易日滚动窗口中，盈利窗口占26.18%，中位收益−8.00%，最差−33.06%；MOM60分别为3.86%、−31.09%、−45.25%。2024年单独盈利不能证明跨年度稳定盈利。

以成熟的未来五交易日开盘到开盘收益为诊断标签，LGB在2023、2024的日均Rank IC分别为0.0591、0.0910，连续样本日均为0.0748，正向日期占69.94%。MOM60同期日均Rank IC分别为−0.0189、−0.0231。这支持继续研究LGB的选股信号，但IC不是可落袋收益，也没有直接证明前20名组合的扣费优势。

## 实际成交成本

连续LGB路径共2,690笔成交，平均每笔3,952.79元，全部触发5元最低佣金。佣金13,450元，实际约为成交额的12.65bp，高于名义万三；过户费106.32元、印花税3,633.86元，交易费合计17,190.18元。模拟不利滑点成本15,496.10元，交易费加滑点共32,686.28元，另有分红税预留796.11元。

滑点规则为2bp不利移动后，向不利方向取一分钱档位，因此实际成本可能明显高于2bp；低价股尤其明显。32,686.28元是这条实际成交路径上的成本汇总，不是可以直接加回净值的“无费收益”：成本会影响后续现金、整手数量、持仓和成交。

连续MOM60共868笔成交，交易费加滑点8,095.57元，显著低于LGB，但净亏损更大；其负Rank IC也提示，问题不只在费用。LGB两年单边换手累计59.14倍、MOM60为17.42倍，定义为买卖成交额合计除以2和平均每日净值，不能把两年累计值写成年换手。

LGB仅4笔跌停队列无法证明可成交而拒单；MOM60有14笔涨停队列拒单、2笔停牌/未知状态拒单。现阶段主要矛盾是选股收益能否覆盖高换手、最低佣金和价格档位成本，而不是多增加页面功能。

成本敏感性已另行冻结并跑完：保留原模型、信号和调仓规则，分别去掉最低佣金门槛、设零不利滑点、以及同时去掉两项，每项完整重跑账本，并先逐项复现基线指标与完整期末账本。八条路径的账务有效性均通过。

- LightGBM取消最低佣金门槛、仍保留万三佣金及其余成本：累计+1.66%，最大回撤30.29%。
- LightGBM零不利滑点、仍保留最低佣金及其余成本：累计+8.62%，最大回撤28.82%。
- LightGBM同时取消两项：累计+21.05%，最大回撤26.28%；这是两年累计收益，不是年化20%。
- MOM60同时取消两项仍累计−25.73%、最大回撤51.65%。

它们是乐观诊断假设，不是现实券商报价、可实现成交承诺、策略切换或新的样本外结论。成本改变还会影响现金、整手数量和后续持仓，情景差额并非孤立的线性费用贡献。LGB值得检验交易频率、目标持仓数量和换仓门槛是否与信号周期匹配；MOM60的缺陷则不能仅靠成本解释。本轮不按这些已观察收益选择新参数。结果保存在`output/research/ashare/experiments/a5_union_primary_cost_sensitivity_20261020_v1/report.json`，原基线不改。

## 数据和训练边界

官方公告逆推的历史成分覆盖2018年至2026年10月19日；每个实际交易日保持300+1000只且两池不重合，未用当前成分回填过去。本轮2023—2024年实际并集为1,743只证券，原价与状态共836,438行、公司行为3,168项；完整市场门禁12项通过。224只复权历史问题股票使用独立原raw/HFQ重建，六只证券七条异常成交额以独立新浪同日原件核对后单独修正派生视图，所有供应商原件保留。

训练使用2017年预热、信号日历史成分与前五日历年数据，按六个实际交易日隔离未来标签；2023年保留1,550,689条训练样本、2024年1,566,375条，共631,346条冻结预测。LightGBM为固定Alpha158、100轮、31叶、深度6、学习率0.03，未按这些收益重新搜索参数。执行使用原历史交易规则、原价、T+1、整手/科创板数量规则、ST/停牌/涨跌停限制和历史印花税。

完整数据门禁通过后，首次回测因原价CSV缺少旧执行器要求的来源文本标签而中止，尚未生成收益。修复仅补入经过原响应SHA校验的内存标签，新协议下重新训练。两年度native模型文件及全部预测CSV与首次训练逐字节一致；旧失败和新完成记录分别保留。

这仍是2026年事后重建的历史检验。训练基座的所有更早日线未逐条重新独立采集，历史数据也是当前取得的供应商版本；此前看过的年份不能包装成全新的未来样本外。研究假设已具备涉及板块权限，日线回测不证明现实队列成交能力。

沪深300价格指数两年累计+1.63%、中证1000价格指数−5.16%，仅作行情环境参照；它们没有分红再投资和交易成本，差额不能直接称作策略alpha。

## 2025—2026年扩展仍须单独通过

该期间1,645只历史成员的原始行情、状态和3,290个分红查询键已经补齐，保留原件与获取时点。原始数据完成不等于可回测：当前还在逐项核验198个非现金分配事件、退市/并购身份以及后复权衔接。

最新一日所需1,198只增量HFQ逐证券、日期、模式配对通过；原固定衔接门禁最初通过1,130只，68只未通过，不能由供应商十进制记录精度与float32误差解释。这68只按全部失败清单、依据数据问题选择整段历史重建，未按收益或股票名称挑选，未放宽门槛。随后全部68只通过原严格整段规则，与已取2025—2026原价逐项一致；1,130只正常增量与68只整段替换形成明确两级新快照，原母快照保留。这只证明价格发布成功，不等于新期间整个市场门禁已通过。

新的公司行为还包括现金分红不足以覆盖完整税额的事件。它们必须保留额外税现金预留或负债，不能把税率剪到100%就当作全税已扣。未完成新期间门禁前，不计算该期间的正式策略收益，也不以2023—2024年通过标志替代。
