# A4：历史执行证据与含费验证

本轮完成2023—2024年沪深300历史执行证据和12组含费对照。预先声明的选择门槛推荐`M1_E2`，活动模拟盘保持原基线。中证1000不在这些收益结果中，不能借用结论。

## 输入与规则

10月20日取得350只历史成员的169,479行原始执行行情、逐日停牌/ST信息、上市身份和700份逐股票逐年份分红响应。保留原始供应商数据，发行人公告补丁在独立文件中；最终消费780条分红送转事件。所有交易日的预期记录覆盖、原价与Qlib价格桥接、除权参考、历史状态和税务证据均通过审计，未解释除权差异为0。

48条资本公积转增的税务依据全部闭合。部分依据公告中明确补税金额或财报科目毛额对账推断，事实文件逐项标注推断方法，原件、URL、SHA和实际下载时间均保留。晚披露财报仅用于重建已发生的会计事实，不作为历史模型预测输入。

交易引擎使用逐日实际生效的规则：T+1、各板块整手及申报数量、涨跌幅限制、上市初期限制、最低5元佣金、双边过户费、卖出印花税在2023年8月28日减半、2bp逆向滑点及不利方向分位取整，以及现金和有证据的应税送股税预留。配股固定不认购，不产生免费新股、现金支出或虚构可交易资产。原A2引擎保留，历史执行放在独立模块。

一例上午成交、下午停牌保留实际收盘价用于估值和下一信号规划，原始停牌标记不改写成全天可交易。其余持仓遇明确停牌时保留上次观察到的会计价格，继续披露估值不完整；这不是可立即清算的资产价值。

## 先固定门槛，再计算收益

原A3候选及参数保持不变。A4有效性和选择策略于2026年10月20日09:56:02（北京时间）冻结，声明SHA为`82730541554c0ccd7a04a1b21c55bfa362abf7409ff4c88f48f8827377e71c3d`；所有真实组合收益在这之后计算。没有根据结果增加候选、改变费用或放宽回撤门槛。

- `M0`：原2012—2022年固定模型，历史段不重训。
- `M1`：按年度使用此前5年滚动训练，相同LightGBM参数和100轮，按下一实际执行交易日的年份路由模型。
- `E0`：原前20名、等权、每5个交易日调仓。
- `E1`：加入排名缓冲，在前40名内保留实际持股数量以减少换手。
- `E2`：在E1上加入此前已观察原始收盘价的整手可负担性检查。

2023为开发年、2024为候选选择年；每年、每组独立从10万元开始。候选须两年均满足会计有效及期末实际价格新鲜；再仅按2024年正收益、最大保守回撤不超过20%、候选收益下界严格胜过基线收益上界筛选。精确Decimal比较，按收益、回撤、成交金额及候选ID确定并列顺序。

## 实际结果

以下是整个年度内实际交易日窗口的**净总收益**，不是年化收益。每组后面的两个数字依次为2023年与2024年；全部12组和费用明细保存在[结果摘要](research/a4_validation_summary.json)。

- `M0_E0`：−2.68%、+21.22%；最大回撤8.79%、6.76%。
- `M0_E1`：+1.91%、+24.33%；最大回撤7.04%、7.58%。
- `M0_E2`：+2.87%、+34.76%；最大回撤7.44%、8.17%。
- `M1_E0`：−5.46%、+21.00%；最大回撤13.95%、9.18%。
- `M1_E1`：−3.91%、+35.81%；最大回撤13.40%、7.62%。
- `M1_E2`：−4.38%、+41.67%；最大回撤14.42%、7.31%。

6组候选在两年均通过已声明的会计有效性门槛，2023年没有不完整估值日；2024年每组有17个来源明确的停牌持仓价格延用日，会计有效但继续标记估值不完整。各组期末价格均新鲜；若有未结清零股权益，也继续保留不完整标记。历史状态的每日00:00是已声明的日生效假设，实际公告发布时间未知。

按固定规则选出`M1_E2`。2024年它成交734笔、佣金3,670元、总显式费用4,680.12元、滑点4,617.22元；基线`M0_E0`为1,170笔、佣金5,850元、显式费用7,320.07元、滑点6,622.41元。两者费用加滑点相差4,645.14元，但不能把净收益差额简单拆成“费用贡献”和“模型贡献”：持仓、资金利用、复利、股数及交易拒绝都同时改变。M1_E2平均非现金权益占比约90.17%，基线约75.18%，额外市场暴露也是比较时必须考虑的差异。

结果说明控制换手和整手买入约束有实际作用，但模型跨年份的稳定性仍不足。滚动模型在2023年三种执行下都落后固定模型；2024年单独比较原执行E0时，滚动模型也未超过固定模型。不能仅凭2024年赢家，就认为模型已经稳定实现20%年收益。

## 策略决定与下一步

保留当前已实际运行的模拟盘及其10月20日真实观察成交，不重置账本、不把新策略填回过去。`M1_E2`进入下一独立模拟候选，需要先把年度5年模型和E2执行规则落实到单独的前瞻实现与冻结版本，再从冻结后的信号开始记录。若在10月20日完成冻结，最早也只能安排之后的实际执行日，不能补填当天早盘。

2024年已经用于选优，不是新的未触碰样本外。2025—2026年此前也已查看，不能反复用来挑参数后继续称作严格样本外；新的证据应来自后续模拟观察。当前还缺少同口径的沪深300全收益基准及风险暴露匹配对照，不能把策略总收益直接称为超额收益。

范围已限定为沪深300和中证1000，见[范围说明](ASHARE_SCOPE.md)；中证1000需要独立补齐原始行情、交易状态、权益处理、逐日成员样本、重训和含费验证。现有沪深300结果只覆盖允许范围中的子集。
