# 研究范围：沪深300与中证1000

研究范围固定为沪深300（000300）和中证1000（000852）的并集，声明见[范围配置](research/ashare_scope.json)。新的股票采集目标、训练样本和买入候选都应从这两个股票池生成，不能回退到全市场、中证500或其他指数。已有持仓的卖出和估值始终可以处理，不会因为退出指数而丢掉账本。

范围按日期变化，不是一张永久固定的股票代码表。回测使用当天有效的历史成分区间；当前成分表只用于有明确来源日期的当前视图，不能用今天的名单回填过去。历史成分仍来自供应商事后整理的区间，尚不等于完整公告时点数据库。

## 与现有验证、模拟盘的关系

现有A3候选和A4开发/验证协议只使用沪深300，是允许范围内的一个子集。它们的模型、数据声明和结果不会重写成“两指数已经共同验证”。中证1000需要独立完成原始交易状态、公司行为、数据接缝和含费验证后，才能加入活动模型的买入候选。

当前每日模拟盘的300只成员与上述官方沪深300名单逐只一致，因此范围调整不会要求其强制卖出或重置账户。原始全市场历史包作为已有实验的不可变来源保留；使用范围通过有日期约束的视图收敛，后续不会因为底层缓存里有某只股票就允许模型交易它。

范围视图会校验两份历史成分或两份当前成分的来源、日期、数量和SHA。缺少任一指数或查询未覆盖日期时拒绝扩大买入范围；既有持仓的减仓、退出和估值不受这一数据缺口阻断。

旧全市场下载/更新入口已在启动采集之前停用，不能先遍历全市场、下载后再筛股票。现有沪深300模拟盘的独立日常采集继续运行；中证1000在原始行情、状态、权益与新模型验证完成前，不通过旧版训练入口直接使用未经修正的历史区间。

范围检查命令为`python main.py research ashare-scope-status --help`。实际派生通过的收据在`output/research/ashare/scope/identity_scope_view_20261020_v1/scope_receipt.json`，其中包含日期范围、原件SHA、当前1,300只名单及历史1,743只有效采集目标。底层研究模块仍可读取完整原快照以重放原实验，新增任务应通过范围对象的目标筛选和逐日训练样本过滤；范围收据本身不证明市场状态和公司行为已完整。
