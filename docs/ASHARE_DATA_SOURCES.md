# A股数据来源与实际用途

本页记录2026年10月20日本地代码和已保存采集收据中的状态。接口存在、一次请求成功、完整历史可用于回测，是三个不同层次；不因某个价格接口能返回K线，就视为它也能提供历史停牌、ST和公司行为。

## 已使用或实际核验的来源

- **Qlib格式历史包**：当前训练特征基座来自社区`chenditc/investment_data`，源声明及版本校验见[`research/a1_qlib_source.json`](research/a1_qlib_source.json)。包含复权价格、成交量、交易日历和供应商整理的历史指数成分区间。Qlib是研究框架和数据格式，不能把社区包称作Qlib生产的官方行情。历史区间也不等于完整公告时点数据库。
- **BaoStock**：本轮原始日线、复权序列、逐日交易状态、逐日ST标记、上市信息和分红事件的主要采集来源。10月20日完成沪深300在2023—2024年历史涉及350只股票的原始执行数据采集，共169,479行；另取得700份逐股票逐年份分红响应。原价与模型特征、公司行为仍须分别审计，接口恢复不等于审计完成。
- **东方财富**：已有直接HTTP、AKShare和efinance入口，用于历史行情、分红及独立价格对照。本轮原始K线请求成功；测试的历史停牌查询忽略了历史日期，故不纳入历史状态证据。K线涨跌额不能直接推算除权日的交易所前收参考价。
- **腾讯财经**：历史价格备用来源；当前个人模拟盘使用其有明确源时间的盘中报价，并检查日期和新鲜度。公共报价不保证成交，项目尚未连接券商委托接口。
- **新浪财经**：原始历史日线备用及交叉核验来源。已对8只股票检查24,185个字段，结果均在声明容差内；对配股除权参考价及一例盘中停牌另做了核对。缺少历史ST或每日交易状态时保持未知，不据此推断可交易。
- **中证指数官网**：沪深300与中证1000的官方当前成分表。10月20日下载的两份文件自身日期均为10月19日，分别300只和1,000只，无交集。它们不能回填2023—2024年的历史成员。
- **交易所、巨潮资讯、发行人原公告、中国结算及税务机关**：公司分红、送转、配股、证券代码变更、涨跌幅制度、整手、过户费、印花税和个人股息税的原始依据。

## 有适配器但尚未成为本轮证据的来源

代码有Tushare Pro适配器，需要相应Token和数据权限；本轮历史验证没有使用Tushare取得的执行证据。不能把“代码支持”写成“当前已完整验证”。

实时行情服务还保留`pytdx`通达信行情入口，本轮也未把它作为历史状态、公司行为或模拟盘执行的已验证主源。行情入口不等于证券账户交易接口。

AKShare和efinance是数据访问工具，其中多项接口依赖东方财富。因此它们有助于兼容和维护，但不能算作两个独立于东方财富的交叉核验来源。

## 当前使用边界

研究和新增采集范围按[`ASHARE_SCOPE.md`](ASHARE_SCOPE.md)收敛至沪深300与中证1000。现有沪深300实验只是这个范围内的子集，中证1000不能沿用其结果宣称已经验证。

当前主要组合为“锁定的历史特征包＋BaoStock原始执行证据＋腾讯盘中观察＋东方财富/新浪价格对照＋官方规则和发行人公告”。不同来源的复权价格须经过逐股票重叠期和单位核验后再接缝，不能直接拼接。所有关键采集保留原始响应、请求参数、获取时间和SHA；未核实的缺口会阻止相应验证或交易，不会补成正常交易记录。

本轮替代来源的实测收据在`output/research/ashare/collections/a4_source_probes_20261020/alternative_source_assessment.json`，官方当前成分原件在`output/research/ashare/collections/scope_current_20261020/`。这些属于本地研究产物，原始数据未纳入Git版本。
